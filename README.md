# SVN 管理（macOS）

基于 SwiftUI 和本机 SVN 命令行的原生 macOS 工具。没有第三方 Swift 包依赖。

## 功能

- 输入仓库地址，查看目录、文件、最后修改版本、提交人和最后上传时间，双击进入目录，返回上级、筛选名称；各列支持点击列头排序。
- 勾选“搜索子目录”后，按名称或相对路径搜索当前目录下所有层级；结果可选择目录签出、双击目录进入，或双击文件定位所在目录。
- 搜索支持“只显示文件夹”，方便查找项目目录并签出。
- 设置中可显示、编辑 SVN 用户配置的全局忽略规则，按目录名、文件名通配符过滤未跟踪待添加项，递归 Add 同样遵守规则；使用同一配置的其他 SVN 客户端也生效。
- 未跟踪项支持右键“忽略”，选择用户全局、仅当前目录或当前目录及所有子目录，再按文件名、文件夹名或扩展名添加规则，自动保存并刷新。
- 工作副本支持“显示已忽略文件”，并可右键“取消忽略”移除匹配的 SVN 用户配置和目录属性规则；确认前展示来源和影响范围，修改前备份。
- 工作副本支持直接显示、编辑目录的 `svn:ignore` / `svn:global-ignores`，分别标明生效范围，并列出继承规则及来源。
- 将当前目录或选中目录签出到本机指定的空目录。
- 签出时打开独立进度窗口，实时滚动显示文件记录、已处理项数与整体百分比，支持取消及暂停自动滚动。
- 更新和提交也会打开独立进度窗口，实时滚动文件和 SVN 消息；更新后批量显示文件最后提交人及提交日期，支持暂停跟随、隐藏窗口与重新打开。
- 打开现有工作副本，刷新状态、更新代码、查看文件差异。
- 文件列表上方提供带数量的状态快捷筛选：全部、已修改、未跟踪、已版本化、待新增、待删除、冲突、缺失、其他；显示已忽略文件时也可单独筛选已忽略项。支持与路径搜索及文件/文件夹类型组合使用。
- 列表上方可“全选当前结果”或“取消当前全选”，包括未跟踪、缺失和可提交项，跳过冲突、已忽略等不可选项；仅影响当前筛选结果，保留其他勾选。
- 按工作副本范围保存提交说明、勾选、筛选和选中行，切换项目后分别恢复，重启自动打开上次工作目录；恢复时重新核对当前文件状态。
- 仓库和工作副本支持提交历史，分页查看版本、作者、时间、说明及变更路径；可选择两个版本和文件并排比较。
- “检查云端更新”只读列出服务器端的新增、删除、修改和属性变化，可单独查看本地同时有修改的项目，不自动执行更新。
- 已版本化且本地存在的文件可右键“查看差异”，左侧本地、右侧云端最新版本并排显示；新增绿色、删除红色、修改橙色，提供真实行号、同步滚动、查找和差异跳转。比较只读、后台运行并支持取消。
- 差异支持 BASE、HEAD 或数字版本；修改行强调变化字符，常见代码提供可关闭的语法着色，支持只保留差异前后各 3 行上下文。
- 文件列表显示类型图标：区分文件夹、链接、代码、项目、配置、文档、图片、压缩包等；仓库浏览与提交检查使用同一套图标。图标按类别缓存，节点类型在后台刷新时读取，行切换不执行额外 SVN 查询。
- 本地文件列表可右键“在访达中打开”或“在 VS Code 中打开”：访达直接打开文件夹、定位并选中文件，VS Code 打开所选文件或目录，无需配置命令行路径。
- 选择未跟踪文件或目录，添加到版本控制；添加目录遵循 SVN 的忽略规则并递归处理，添加后重新检查清单。
- 将本地缺失的路径标记为待删除，提交后才删除服务器版本。
- 勾选提交项，填写说明，检查清单后 commit 到服务器。
- 最近仓库、最近工作副本支持固定到各自列表顶部，重启后保留；提供会话操作记录及 SVN 路径设置。
- 仓库地址、工作副本信息和弹窗中的 URL 直接显示中文，保留地址中的特殊字符转义以保证复制后仍访问原路径。
- 浏览仓库时弹窗登录，成功连接后将账号密码按仓库记入 macOS 钥匙串，同仓库后续访问及重启应用后自动登录。

## 运行

要求 macOS 14 或以上，已安装 SVN 1.14 或以上。构建需要 Swift 6 工具链（Xcode 或 Command Line Tools）。

```zsh
./scripts/build-app.sh
open build/SVN管理.app
```

本机构建生成当前 Mac 架构的应用，位于 `build/SVN管理.app`。应用使用本地临时签名，尚未进行 Developer ID 签名或公证。SVN 可执行文件未打入应用，目标 Mac 仍需安装 SVN；在应用“设置”中可选择实际路径。已有 Homebrew 时可以使用 `brew install subversion` 安装。

开发运行及测试：

```zsh
./scripts/swift.sh run SVNManager
./scripts/test.sh
# 仅运行目录忽略属性的相关检查
./scripts/test.sh --filter directory-ignore
```

构建脚本将编译缓存与中间文件限定在项目 `work/`，不修改全局 Swift 设置。

仅安装 Command Line Tools 27 且缺少 SwiftUI 宏插件时，脚本会使用本机已安装的 macOS 26 SDK 构建；可通过 `SVN_MANAGER_SDK=/完整/SDK路径 ./scripts/build-app.sh` 指定 SDK。此兼容选择只影响项目命令。

验收程序直接运行 Swift 检查，无需 XCTest 或 Swift Testing 运行库，只有 Command Line Tools 的环境也可执行。

## 使用流程

1. 左侧输入完整 SVN 地址，点击“连接并浏览”。HTTP(S) 和 SVN 仓库首次访问会弹出登录窗口，用户名和密码均需填写；点击“登录并记住”，成功连接后自动保存到 macOS 钥匙串。同仓库的子目录、后续签出、更新及提交不再重复输入，重启应用后仍可使用。支持 `https://`、`http://`、`svn://`、`svn+ssh://`、`file://`，不支持普通网页式的“全部仓库发现”；地址须为 SVN 可访问的仓库或其中的目录。
2. 双击目录进入，点击“签出”。普通浏览时，选中目录会签出所选目录，未选中目录时签出当前目录；搜索结果中需先选中目录。在文件夹选择窗口新建空目录，代码直接落到所选目录。
3. 也可以选择“打开已有工作副本”，打开已有 `.svn` 工作副本中的目录。只管理选择的范围，不自动扩大到工作副本根目录。
4. 修改本地文件后刷新。右键文件选择“查看差异”，左侧显示本地全文，右侧显示读取时的云端最新版本及版本号。颜色表示本地相对云端的增删改，空位用于对齐。工具栏“查看差异”及双击对已版本化文件同样并排显示，但右侧为签出基线（BASE）；目录属性等其他差异仍使用文本说明。
5. 未跟踪文件或目录可以选中一行后点击工具栏“Add”，也可以勾选多项后批量 Add，或右键选择“Add 到版本控制”。确认清单后状态变为“待新增”。目录会递归添加，刷新后检查新增清单并勾选需要提交的项目，原来其他文件的提交勾选会保留。新目录及其必要的新增父目录也须一起勾选。
6. 勾选待提交项并填写说明，点击“检查并提交”，核对服务器地址、文件清单和说明后提交。确认弹窗按屏幕和窗口限制尺寸，标题与底部操作按钮固定显示，长文件清单和提交说明分别在中间滚动。

不需要添加的未跟踪项可右键选择“忽略”，先选生效范围，再选文件名、文件夹名或扩展名规则。“用户全局”写入 SVN 用户配置的 `global-ignores`，对使用同一配置的所有工作副本生效；“仅当前目录”写入所选项目所在目录的 `svn:ignore`；“当前目录及所有子目录”写入该目录的 `svn:global-ignores`。这里的当前目录指所选项目的直属版本化父目录，菜单会显示相对位置；忽略一个未跟踪文件夹时规则也写到其父目录。目录属性修改保存在本地，提交相应目录后才共享到服务器，不自动 Add 或提交。

菜单直接显示将追加的规则，保留已有规则及其他属性。名称中的通配符字符会转义；用户全局范围中的空白会替换为 `?` 并提示，两个目录范围则保留名称中的空格。状态已变化、父目录未纳入版本控制或路径异常时停止操作；写入前备份、写入后读回，后台刷新并保留其他提交勾选和草稿。规则仅过滤未跟踪项，不删除本地文件；可通过全局设置、目录属性编辑或右键“取消忽略”管理。

勾选“显示已忽略文件”后，列表会同时显示 SVN 用户全局过滤和目录属性规则忽略的项目，标为“已忽略”并单独计数；开关在重启后保留，忽略文件夹仅显示该目录，不额外遍历其中内容。忽略项不能直接勾选、Add 或提交。右键“取消忽略…”后会先在后台检查当前状态和规则来源，确认窗口列出将移除的全部重叠规则及范围；确认后按来源保存并刷新，对应范围中匹配这些规则的未跟踪项会恢复显示，其他提交勾选保留。SVN 原有配置、目录的 svn:ignore 以及本地上级目录继承的 svn:global-ignores 也支持直接取消。确认窗口按来源列出配置文件、属性名称、来源目录及影响范围；移除全部匹配规则后保留其他规则。SVN 系统配置和默认规则通过用户配置覆盖，不修改系统文件；原用户配置先备份，再最小修改并核对内容、权限和扩展属性。属性备份保存在应用支持目录的 IgnoreBackups 中，属性修改保留为本地变更，须检查并提交后才同步到服务器。若继承规则位于尚未签出的仓库上级目录，需先签出来源目录再修改。确认期间来源变化会停止写入，写入失败保留备份、不自动重试或回滚。取消忽略不自动 Add 或提交。

签出前先读取版本并递归统计文件、目录清单，再固定该版本签出，避免服务器同时新增文件导致总数变化。准备阶段显示统计提示；下载阶段按已处理项数计算百分比（不是传输字节比例），SVN 确认成功后显示 100%。统计清单会增加一次递归目录读取的耗时。记录在后台按输出块解析，界面每 100 毫秒批量接收更新，列表仅渲染可见行。关闭进度窗口后签出继续进行，可从主窗口底部“签出进度…”重新打开；需要停止时点击“取消签出”。失败或取消可能留下部分本地文件，请检查目标目录。

更新与提交进度同样在后台接收实际 SVN 输出，每 100 毫秒合并刷新，列表仅绘制可见行并保留最近 10,000 条记录。可暂停“自动滚动到最新文件”浏览先前记录；隐藏窗口后任务继续，可从主窗口底部“更新进度…”或“提交进度…”重新打开。更新不为统计百分比提前遍历仓库，进行中显示已接收的文件和目录通知数，SVN 确认完成后显示 100%。提交根据显式勾选路径的发送通知显示进度，发送完毕仍需等待服务器返回提交版本号，确认后才显示 100%；不会自动重放失败或结果不明的提交。

更新下载结束后，工具只对本次记录中保留的路径分批读取本地 SVN 元数据，补齐“最后提交人”和“最后提交日期”，不逐个文件访问服务器，不把下载时间当作提交时间。日期按本机时区显示；删除项目标为已删除，不套用旧提交人，无法读取的元数据明确显示未提供。补全失败或被取消不会重做已完成的更新。更新执行阶段可以取消；提交写入阶段不提供中断。SVN 已确认完成但本地状态刷新失败时，进度窗口会说明已完成及尚需检查的事项，避免重复执行。

提交使用显式路径和 `--depth empty`，不会因为勾选目录属性而递归提交未勾选的子文件。新增目录的未选中文件保留在本地待新增状态；删除目录本身代表删除整个目录，请检查清单。已有冲突、属性冲突、树冲突及阻塞项禁止直接提交，需先用外部 SVN 工具解决。暂不提供撤销修改、分支合并及冲突编辑器。

仓库列表的选中状态仅在列表内部更新，不触发整个应用刷新或仓库读取。双击整行（包含版本等其他列）可进入目录；单击只切换高亮和签出目标。

云端文件比较只读取所选文件，不执行更新、覆盖或提交，保留当前提交勾选和草稿。先锁定云端数字版本，再读取同一版本的全文。比较依据实际内容解码，支持 UTF-8、UTF-16 和中文常用 GB18030/GBK；即使源码的 `svn:mime-type` 被错设为 `application/octet-stream`，文本仍可并排显示，不修改该属性。实际图片、压缩包及含有二进制控制内容的文件会明确提示不支持文本比较。

左右正文完整对齐并按可见行绘制，横向和纵向双向同步滚动，两侧使用相同的滚动范围；可按 ⌘F 在任一侧查找，使用上一处/下一处差异跳转，按 ⌘C 复制选中行或使用“复制全文”。单侧最多 4 MiB、50,000 行，超限明确提示，不把截断内容作为完整文件比较；极长单行限制预览长度，可复制全文。大范围无共同锚点时会提示按行配对，原文仍完整保留。CRLF/CR/LF 会规范化后比较正文，原换行格式在标题中显示，末尾换行差异单独提示。尚未提交的新文件、未跟踪项、目录及本地缺失项不可进行云端文件比较；云端对应路径删除或不可访问时提示错误。

差异窗口上方可选择“签出基线 BASE”“云端最新 HEAD”或输入数字版本，点击“读取对照版本”后才重新读取；输入版本号不会发起请求，读取失败时保留上一次成功结果并提示。指定版本沿本地节点历史读取；云端更新窗口中的比较则固定读取本次检查版本的对应路径。字符级强调在后台准备，代码着色仅处理可见行并使用有界缓存；折叠未变化内容仍保留真实行号，查找隐藏行时会自动展开，复制全文始终保留完整内容。

项目状态以本地选定范围、仓库根地址和目录映射共同隔离，切换过分支的目录不会套用旧分支草稿。编辑后合并保存到应用支持目录中的 ProjectStates，切换前和退出前等待保存；磁盘写入在后台进行，保存失败会提示且取消退出。成功提交后保存清空的说明和勾选；刷新只保留仍有效的勾选。单项目说明最多 128 KiB、勾选最多 10,000 项、完整状态最多 512 KiB，超过时保留旧草稿并提示，不静默截断；保留最近 100 个项目状态。正在执行 SVN 操作时，需完成或取消后再退出。

状态快捷筛选只改变列表展示，不增删文件、不改变提交勾选，也不执行额外 SVN 查询。状态按钮的数量会随路径搜索和类型选择变化；“已修改”包含仅属性修改，文本、属性和树冲突统一归入“冲突”，“其他”包括替换、阻塞等状态。“已版本化”指当前变更清单中已经纳入版本控制的项目，不额外列出无修改的文件。文件/文件夹按已读取的节点类型判断，无法判断类型的项目保留在“全部类型”中。筛选在后台完成，快速切换会取消旧结果；没有匹配项时显示独立提示，避免误认为工作副本没有变更。

“清除筛选”同时恢复全部状态、全部类型和空路径搜索。筛选条件按项目保存并支持重启恢复，旧版草稿缺少新筛选字段时仍保留原提交说明和勾选。隐藏的勾选项会显示数量提示，提交前的检查窗口仍列出所有勾选项；“勾选可提交项”只增加当前结果中的可提交项目，保留其他勾选，“清空勾选”则清除全部勾选。

“提交历史”可查看当前目录，也可从右键查看单个已跟踪文件或目录。首次锁定数字快照，每次读取最多 100 条，后续“加载更早记录”保持同一快照；筛选只作用于已经加载的作者、日期、说明和版本。窗口最多缓存 2,000 条或 32 MiB，达到上限时提示进入更具体范围。按住 ⌘ 选择两个版本，再选变更文件比较，左侧为较新版本、右侧为较早版本。某个版本中不存在的新增、删除路径会明确报错，不以其他版本代替。历史读取和比较可取消。

“检查云端更新”比较服务器状态与当前工作副本基线，不更新、覆盖或提交任何文件。列表可过滤路径，或仅显示本地也有修改的项目；同时修改只表示需要检查，不代表已经发生合并冲突。云端新增而本地不存在的节点、已删除节点和目录不提供文本比较。关闭检查窗口后再决定是否点击“更新”；提交检查页也提供只读云端检查入口，提交草稿与勾选保留。单次清单最多 16 MiB、20,000 个变更，超限时提示缩小目录范围。

“最近工作副本”和“最近仓库”每项右侧的图钉可固定或取消固定，也可以使用右键菜单。新固定项排在各自固定区最前，后续打开其他项目不会改变固定顺序。普通最近项保留 10 个，固定项不受此上限影响；设置中的“清空最近记录”仅清空未固定项。

列表默认按名称自然升序排列（例如 Folder2 在 Folder10 前），文件夹排在文件前。点击名称、版本、最后提交人、最后上传时间或大小的列头，可切换升序与降序；版本、大小和时间按实际数值比较，浏览其他目录时保留本次会话所选排序。“最后上传时间”取 SVN 记录的该条目最后提交时间，按本机时区显示；文件夹显示目录节点的提交时间。

已记住账号的仓库浏览直接执行目录读取，省去每次进入目录前重复的仓库信息查询。目录结果在内存中缓存 30 秒，返回上级或再次进入近期目录可直接显示；点击刷新、连接并浏览或按 Command-R 会重新读取服务器。更换账号或提交成功后清除缓存。

默认搜索框仅筛选当前层级。需要遍历子目录时，勾选“搜索子目录”，输入名称或相对路径关键词，再按回车或点击“搜索”。匹配不区分大小写，也支持中文；结果以完整相对路径区分不同目录下的同名文件，保留版本、提交人、时间与大小。搜索只读取目录清单，不下载文件内容；每次确认搜索执行一次递归目录读取，耗时取决于仓库规模及服务器响应，输入过程不自动请求。读取、解析和排序在后台进行，支持“取消搜索”。最多显示前 5000 个匹配项，同时显示完整匹配数量，超出时请缩小关键词或先进入更具体的目录。点击“返回当前目录”恢复原列表；未选中目录时，搜索结果中的签出按钮保持禁用。

“只显示文件夹”同时适用于当前层级和递归搜索。递归搜索先按目录类型过滤，再统计匹配数量及应用 5000 项上限，文件不会占用目录结果名额；在已有搜索结果上切换该选项，会按当前关键词重新搜索。

在“设置 → SVN 用户全局过滤”中直接查看、编辑 `~/.subversion/config` 的 `[miscellany] global-ignores`，界面显示配置路径及当前规则来源。尚无用户设置时显示继承的系统配置或 SVN 默认规则；保存会写入用户配置覆盖。每行填写一个名称或通配符，例如 `bin`、`obj`、`*.log`，点击“保存到用户配置”。规则按文件或文件夹名称匹配，支持 SVN 的 `*`、`?`、`[abc]`，不填写相对路径；名称中的空格可用 `?` 匹配。保存后读回确认并刷新当前工作副本，其他使用此用户配置的 SVN 客户端同样生效；右键“忽略 → 用户全局”也写入同一配置。旧版仅存于工具中的规则会带入编辑框并注明，显式保存后迁移到用户配置并移除旧设置。

修改前备份原用户配置，保留无关选项、注释及权限；配置在编辑期间被外部修改时停止保存，可点“重新读取”载入最新内容。清空并保存会写入显式空规则，关闭用户级全局忽略；目录的 `svn:ignore` / `svn:global-ignores` 仍独立生效。忽略仅作用于未纳入版本控制的项目，已跟踪文件的修改仍会显示。

在工作副本中点击“目录忽略属性…”，或右键某一行进入对应目录的属性编辑页；也可在编辑页中“选择目录”。`svn:ignore` 只影响该目录下一层的未跟踪文件和文件夹，`svn:global-ignores` 影响该目录内及所有子目录中的未跟踪项。每行一个名称或通配符，名称中的空格按字面匹配。继承的 `svn:global-ignores` 单独列出来源和生效范围；本地祖先目录可点击“编辑来源目录”，尚未签出的仓库来源只读，需先签出来源目录后再编辑。上级目录的 `svn:ignore` 不会在当前目录继承生效。

“保存目录属性”仅修改所示目录的两个忽略属性，保留其他属性，保存后刷新原工作副本范围并保留提交勾选及草稿；属性变更需检查并提交相应目录后才同步到服务器。清空会移除本目录的对应属性，用户全局规则和祖先继承规则仍有效。写入前备份原属性，编辑期间来源或状态变化会阻止保存；失败时检查已发生的本地变化及备份，重新读取后再编辑，不自动重试或提交。读取与保存均在后台进行，切换文件行不触发属性查询。

## 认证与操作结果

- 账号密码在成功连接后保存到 macOS 登录钥匙串，仅在钥匙串解锁时读取，不同步到 iCloud。密码经标准输入交给 SVN，不写入应用偏好、命令参数或操作记录；SVN 本身继续使用 `--no-auth-cache`，应用独立管理记忆的凭据。
- 凭据以服务器返回的仓库根地址划分，按协议、主机、端口及目录边界匹配，同一仓库的子目录共用，不同仓库分别登录。清空最近记录不会删除保存的账号。
- 已保存的账号认证失败时重新弹窗；可用左侧“更换当前仓库账号”主动替换。网络、证书和权限错误不当作密码错误反复重试。更新、提交前先执行只读认证检查，提交命令本身失败不会自动重放。
- 本地 `file://` 仓库无需账号密码；`svn+ssh://` 继续使用已配置的 SSH 密钥与代理，不弹出 SVN 密码窗口。
- 最近使用的仓库地址和本地路径保存到应用偏好。仓库 URL 不允许嵌入账号密码或查询参数，防止凭据进入最近记录。
- 按 SVN 默认规则检查服务器证书，不自动忽略过期、主机名不匹配或不可信证书。自签名证书请在终端核对来源后建立信任。
- `svn+ssh://` 依赖本机已经配置好的 SSH 密钥、SSH agent 及主机信任，不支持在界面中交互式输入 SSH 密码。
- 签出和更新忽略 `svn:externals`；外部引用应单独管理。
- 浏览、签出、差异与更新可取消；签出或更新中止后可能已有部分本地结果，应检查目录。提交、本地添加/删除标记及取消忽略的写入阶段不提供取消。
- 提交错误不会自动重放。网络中断时服务器可能已经接收写入，应先刷新、核对服务器版本再操作；提交成功但刷新失败时会明确提示已成功执行。
